# 极简工作台三步主线（批准版 v3）

用户确认：新建项目→新建需求→获得成果是主线，面向非专业用户处理非代码任务。新建需求仍必须选择模板；业务流程沿用当前能力，简化信息层级。用户批准 HTML 原型 v3 并授权视觉精修后实施。此前分栏专业工作台方向不再适用。

## 页面与交互
- 左侧仅项目列表；宽屏充分使用空间，窄屏切换为项目选择器。
- 中心始终保留三步引导，按当前项目/操作突出下一步。项目未建立时仍可点击第1步；后续步骤明确空态。
- 当前项目需求用紧凑列表展示真实状态和查看入口。过程、模板说明及执行明细按需展开；不得伪造完成、百分比或演示成果。
- 新建项目保留项目名、已有工作目录、动态模板类型；默认普通业务模板，其他配置按需展开。当前没有上传API，保留目录/资料路径输入，不把浏览器文件名当作服务端可读路径。
- 新建需求先选模板，再描述目标。标题可选，未填时取需求前80字；模板搜索/分类保留为可展开辅助，模板所需上下文按真实schema出现且必填字段不折叠。非代码模板排除已知eng/sys分类，未知自定义分类保留。
- 成果使用原有归属/路径安全API；最多三项可用文件/链接为摘要，完整记录可展开；预览/下载/部分失败/不可读原因保留。无文件不等于业务失败，执行完成也不等于已交付。
- 顶栏工作台切换保留项目/需求，旧研发工作流仍可读。

## 验收与范围
空态、模板自定义/搜索/记忆、切换项目旧响应隔离、启动job失败恢复、普通目录真实持久化、裁决及文件预览下载、移动端与键盘均验证。只修改前端、回归及相关文档；无新后端/依赖/运行状态。交付为本地候选，生产升级另行授权。
